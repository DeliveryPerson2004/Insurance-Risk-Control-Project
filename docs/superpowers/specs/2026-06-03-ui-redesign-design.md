# UI 重设计 · 设计规格书

> 日期: 2026-06-03 | 状态: 待审核 | 技能: brainstorming + ui-ux-pro-max

## 1. 问题诊断

现有 UI 存在以下问题：

- **登录页**：紫色渐变 (`#667eea → #764ba2`) — AI 生成痕迹重
- **全局**：`index.css` 仅 `body { margin: 0 }`，ConfigProvider 仅设 `colorPrimary: '#1677ff'`
- **布局**：标准 Ant Design 暗色侧边栏，无品牌辨识度
- **组件**：硬编码颜色散落各处 (`#cf1322`, `#3f8600`, `#1677ff`, `#ff4d4f`, `#666`...)
- **仪表盘**：4 统计卡片 + 图/表左右分栏，无页面级视觉层次
- **预测表单**：折叠面板/向导切换增加交互复杂度
- **各页面**：Ant Design 默认样式裸奔，无设计感

## 2. 设计系统

### 2.1 风格方向

**Warm Slate + Olive** — 极简克制、温润、专业

| 维度 | 决定 |
|------|------|
| 基底 | Warm Slate (灰中混入极少量暖褐) |
| 强调色 | Olive `#4A5630` — 沉静、医疗+自然联想 |
| 字体 | Inter (Google Fonts), 全站统一 |
| 侧边栏 | 浅色微妙区分 (`#EBE8E4` vs 内容区 `#FAFAF9`)，不折叠 |
| 导航 | 图标 + 文字标签始终可见 |
| 仪表盘 | Editorial 非对称布局 (60/40) |

### 2.2 色彩体系

```

├─ 文字 ─────────────────────────────────────────┤
│  Foreground    #292524    (主文字)              │
│  Secondary     #44403C    (次要文字)             │
│  Muted         #6B625D    (辅助/说明，≥4.5:1)   │

├─ 语义色 ───────────────────────────────────────┤
│  Danger        #DC2626    (高风险/删除/拒绝)      │
```

### 2.3 字体

```
Font Family: Inter
  @import url('https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600;700&display=swap');

  Heading:  font-weight 600, letter-spacing -0.02em
  Body:     font-weight 400, line-height 1.6
  Caption:  font-weight 400, font-size 12px, color Muted
  Data:     font-weight 500, font-feature-settings: 'tnum' (等宽数字)

Scale: 12 / 14 / 16 / 18 / 24 / 32 / 40
  (40 为极端场景预留，日常主用 12-32)
```

### 2.4 间距 & 圆角 & 阴影

```
Spacing:  4 / 8 / 12 / 16 / 24 / 32 / 48  (4px 基准)
  Content padding: 32px (宽松留白)
  Card padding: 24px
  Section gap: 24px

Radius:   6px (卡片/按钮), 4px (输入框/Tag)

Shadow (3 层梯度):
  Card:     0 1px 2px  rgba(0,0,0,0.04)  — 极轻
  Dropdown: 0 4px 12px rgba(0,0,0,0.08)  — 浮层
  Dialog:   0 8px 24px rgba(0,0,0,0.10)  — 模态
```

### 2.5 对比度验证

| 组合 | 用途 | 对比度 | 评级 |
|------|------|--------|------|
| `#292524` on `#FAFAF9` | 正文/浅底 | 16.2:1 | AAA ✓ |
| `#44403C` on `#FAFAF9` | 次要文字 | 9.7:1 | AAA ✓ |
| `#6B625D` on `#FAFAF9` | 辅助文字 | 5.1:1 | AA ✓ |
| `#FFFFFF` on `#4A5630` | 主按钮白字 | 4.8:1 | AA ✓ |
| `#DC2626` on `#FAFAF9` | 危险/高风险 | 5.5:1 | AA ✓ |
| `#B7870A` on `#FAFAF9` | 警告/中风险 | 3.2:1 | 仅支持大文本 |

> ⚠️ Warning `#B7870A` 小字不过 AA。实际用于 Tag 组件（加粗 600 字号 12px+）或需调整为 `#947008`。

## 3. 布局骨架

```
┌──────────────────────────────────────┐
│ Header (面包屑/标题 · 右侧用户+退出) │ bg: #FAFAF9
├────────┬─────────────────────────────┤
│ Sider  │ Content                     │
│ #EBE8E4│ #FAFAF9                     │
│ 220px  │ padding: 32px               │
│        │                             │
│ · 仪表盘│  页面标题 + 副标题/日期      │
│ · 单条  │  ─────────────────────     │
│ · 批量  │  内容卡片                   │
│ · 案件  │                             │
│        │                             │
│ ────── │                             │
│ · 管理  │                             │
└────────┴─────────────────────────────┘
```

原则：
- 侧边栏图标+文字始终可见，不折叠
- Header 融入 Content BG，去掉 Ant Design 默认彩色背景
- 面包屑取代独立 `<h2>` 标题行
- 内容区 32px padding（从当前 24px 放宽）

## 5. 反面清单 (Anti-patterns)

以下是本次设计明确要避免的：

| 类别 | 避免 | 替代 |
|------|------|------|
| 颜色 | 紫色/粉色渐变 | Warm Slate 中性底 |
| 颜色 | 霓虹色/荧光色 | Olive + 低饱和语义色 |
| 动画 | 花哨过度动画 | 150-300ms 微妙过渡 |
| 图标 | Emoji | @ant-design/icons |
| 字体 | 多种字体混搭 | Inter 全站统一 |
| 对比度 | 灰色文字过低对比度 | 全部 ≥ 4.5:1 (AA) |
| 交互 | 炫技式交互 | 功能优先，降低认知负荷 |
| 组件 | Ant Design 默认样式裸奔 | 统一 Token 覆盖 |
